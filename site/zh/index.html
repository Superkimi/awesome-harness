01 · PROJECTS

25 条实现路线

01

MCP-first desktop/server harness

OpenWork

OpenWork 把桌面工作区、OpenCode 会话和 MCP Apps 组合成一个可观察的工作台；它的关键不是“能聊天”，而是把界面状态、会话路由、插件装配和沙箱边界做成可验证的协议。

技术分析 ↗小白教程 ↗51902a94b1d1
02

Local-first multi-agent cowork desktop

Eigent

Eigent 把单 Agent、Workforce、多模态工具、MCP 与本地记忆放进一个桌面 Cowork 工作流。源码里最值得学习的是任务锁、上下文构建、动作协议和跨重启记忆，而不是 UI 上的“多 Agent”按钮。

技术分析 ↗小白教程 ↗88d837f75ad9
03

Agent control plane with runtimes

Multica

Multica 把 Agent、Runtime、Task、Skill 和 Composio 工具放进一个可运维控制面。它的源码重点是资源生命周期：删除 runtime 前先处理绑定 Agent，任务与用量可查询，工具版本与连接账户显式传递。

技术分析 ↗小白教程 ↗d467cc906915
04

Coding agent with microkernel and Compose

MiMo-Code

MiMo-Code 的源码把 Coding Agent 拆成 microkernel runtime、Compose 编排、插件工具、全局同步、权限和 context budget。它适合研究“内核保持稳定，能力从插件/技能/工作流注入”的工程路线。

技术分析 ↗小白教程 ↗332d7b0db65c
05

Local-first desktop agent with workflow graph

Kun

Kun 把 Direct 模式、Agent Graph、工作流运行时、扩展 API、权限和本地恢复放进一个桌面 Agent。它的核心学习点是：复杂任务不是多喊几个模型，而是把节点状态、取消、审批、恢复和插件契约做成一套运行时。

技术分析 ↗小白教程 ↗1377249652ce
06

Desktop agent with Tape, ACP, memory, and subagents

DeepChat

DeepChat 把对话运行时拆成 SessionTurn、Tape/Transcript、工具 effect、Memory lineage、ACP 与 Subagent slots。它特别适合学习“聊天产品如何升级成可恢复 Agent Harness”。

技术分析 ↗小白教程 ↗d5e41ce0bb9e
07

Semantic diagram design skill

Diagram Design

Diagram Design 不是一个 Agent runtime，而是一套把语义模式、图形类型、复杂度预算、连接器规则和可访问性检查固化进 Skill 的 Harness。它是这批项目里最适合研究“如何让模型稳定产出技术图”的样本。
