L1factcollaboration

01 · 子 Agent 统一为可订阅、可重放、可中止的 AgentProtocol

SOURCE FACT

AgentSession 包装 send/subscribe/abort/events，并把一次 stream 限定在 agent_start→agent_end；它先订阅再回放历史，处理 setup 期间 early events，支持按 eventId 或 streamId 重接。

PLAIN LANGUAGE

无论子 Agent 在本机还是远程，上层看到的都是一条带编号、能续看的事件流。

IMPLICATION

UI、SDK 与 A2A server 可共享协议，断线恢复不必理解每种 executor。

L1limitationcollaboration

02 · Local 子 Agent 支持后台执行和取消，但同一 protocol 实例不允许并发 stream

SOURCE FACT

LocalSubagentProtocol 在 send(message) 时若已有 activeStreamId 直接报错；它用 setTimeout 后台启动，独立 AbortController，取消时丢弃 partial output 并返回空 aborted result。

PLAIN LANGUAGE

一个子 Agent 会话一次只接一单；主线程能先拿到 streamId，不必等它做完，但不能同时塞第二单。

IMPLICATION

并发应通过多个 Agent 实例而非重入同一实例，取消的部分成果不会自动保留。
