IMPLICATION

SOURCE FACT

技能、知识、计划与研究 brief 默认作为隐藏 custom message 放在用户消息后，而不是改 system prompt；字节相同的块不重复注入。可用环境变量切回旧 system 模式。

    1  // Where little-coder's per-turn context augmentation lands (issue #73).
    2  //
    3  // Four extensions add a block of guidance to a turn: skill-inject (tool skill
    4  // cards + the research directive), knowledge-inject (algorithm reference
    5  // entries), plan-mode (planning instructions + research), and deep-research
    6  // (the report brief). All four used to append to the SYSTEM PROMPT.
    7  //
    8  // That destroyed the KV cache. The system prompt is the first thing in the
    9  // request, so changing it invalidates the entire cached prefix — and these
   10  // blocks are recomputed per turn from the user's prompt, so they changed
   11  // almost every turn. manueloverride caught it with `cache-hunter`: llama.cpp
   12  // re-churning 120k of message history "for no reason" mid-conversation.
   13  //
   14  // pi already has the right hook. `before_agent_start` may return a `message`
   15  // instead of a `systemPrompt` (core/extensions/types.d.ts::
   16  // BeforeAgentStartEventResult); pi appends it AFTER the user's message
   17  // (core/agent-session.js) and converts `role: "custom"` to a `user` message on
   18  // the way to the provider (core/messages.js::convertToLlm). So the block lands
   19  // at the TAIL of the conversation with every preceding byte untouched — the
   20  // prefix stays cached and only the new tokens are processed.
   21  //
   22  // The recency argument that put these blocks last in the system prompt gets
   23  // stronger, not weaker: small models weight the end of the context most, and
   24  // the conversation tail is as late as it gets.
   25  //
   26  // `LITTLE_CODER_INJECT_MODE=system` restores the old system-prompt behavior,
   27  // which is what the whitepaper scaffold reproduction was measured against.
   28
   29  export type InjectMode = "message" | "system";

   38      display: boolean;

   43    return env.LITTLE_CODER_INJECT_MODE === "system" ? "system" : "message";
   44  }

   46  /**
   47   * Build the `before_agent_start` return value for a block of injected guidance.
   48   *
   49   * @param customType  Stable id for this injector (`lc-skills`, `lc-knowledge`,
   50   *                    …) so the blocks are distinguishable in the session log.
   51   * @param block       The text to inject. Returns undefined when empty.
   52   * @param systemPrompt The turn's system prompt — only read in `system` mode.
   53   */
   54  export function injectionResult(
   55    customType: string,
   56    block: string,
   57    systemPrompt = "",
   58    env: NodeJS.ProcessEnv = process.env,
   59  ): InjectionResult | undefined {
   60    if (!block) return undefined;
   61    if (injectMode(env) === "system") {
   62      return { systemPrompt: systemPrompt + block };
   63    }
   64    return { message: { customType, content: block, display: false } };
   65  }
   66
   67  /**
   68   * Suppress a block that is byte-identical to the one this injector added last.
   69   *
   70   * A tail message persists in the conversation, unlike a system prompt that is
   71   * rebuilt each turn — so re-sending the same skill cards every turn would pile
   72   * up duplicate copies and spend context for nothing. The previous copy is
   73   * still there and still visible to the model, so skipping is free.
   74   *
   75   * Returns a `shouldInject` predicate that remembers the last block it accepted.
   76   * In `system` mode it always returns true: there the block is rebuilt from
   77   * scratch each turn and skipping it would drop the guidance entirely.
   78   */
   79  export function makeDedupe(env: NodeJS.ProcessEnv = process.env): (block: string) => boolean {
   80    let last: string | null = null;
   81    return (block: string): boolean => {
   82      if (injectMode(env) === "system") return true;
   83      if (block === last) return false;
   84      last = block;
   85      return true;
   86    };
   87  }
