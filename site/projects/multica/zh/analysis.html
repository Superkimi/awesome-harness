01 · 结论先行

先用一句话抓住它的控制面

Multica 把 Agent、Runtime、Task、Skill 和 Composio 工具放进一个可运维控制面。它的源码重点是资源生命周期：删除 runtime 前先处理绑定 Agent，任务与用量可查询，工具版本与连接账户显式传递。

优势

  • Runtime 与 Agent 解耦，支持重绑和级联删除策略
  • CLI/API/桌面/移动端共享资源模型
  • Composio 工具请求显式携带连接账户与版本

边界

  • 控制面很强，但实际执行安全取决于 runtime 实现
  • Go server、web、desktop、mobile 组件多，升级协调成本高
  • CLI 删除操作需要用户理解 active-agent 冲突与 cascade 语义
