01 · The sandbox provider selects a runner before wrapping argv

SOURCE FACT

sandbox-local defines bwrap→Landlock on Linux, Seatbelt on macOS, and restricted-token ACL on Windows; confine returns runner argv, enforcement, and failure rules.

PLAIN LANGUAGE

The executor receives an OS-constrained command, not the raw argv.

IMPLICATION

Sandboxing should be an execution seam shared by shell, PTY, and LSP consumers.

02 · Failed confinement probes fail closed instead of running raw argv

SOURCE FACT

sandbox-local documents and implements SANDBOX_UNAVAILABLE when a runner is unusable; it does not return the original argv.

PLAIN LANGUAGE

Without bwrap or sandbox-exec, the Agent refuses to execute rather than silently falling back to the host shell.

Deployment checks should treat runner availability as a preflight gate.

SOURCE FACT

Tool ask/deny/allow is a policy decision, while sandbox-local confine wraps argv in an OS runner; they live in separate packages and seams.

PLAIN LANGUAGE

Asking the user for permission does not replace limiting which files a command can touch.

Security UI and audit logs should show approval and enforcement separately.
