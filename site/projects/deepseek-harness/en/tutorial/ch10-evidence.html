01 · JSONL persistence avoids torn reads with a stable stat/read loop

SOURCE FACT

readStableFile compares fileRevision before and after readFile and retries if a writer appended; readRaw preserves the original JSONL text and compressed frames.

PLAIN LANGUAGE

Recovery does not mistake a session being written for a complete fact.

IMPLICATION

Persistence readers must account for concurrent writers rather than calling readFile once.

  239    /**
  240     * Read a session's stored artifact text verbatim: the durable file bytes
  241     * decoded from this backend's physical encoding (complete zstd frames
  242     * concatenated, or UTF-8 plaintext). The content is the exact JSONL text the
  243     * backend wrote — never a reconstruction from parsed events — so packed-
  244     * chunk rows, key order, and line breaks survive byte-for-byte. A torn
  245     * final frame is omitted, matching the committed-prefix semantics of every
  246     * other read.
  247     * @param id - the persisted session to read.
  248     * @param signal - optional cancellation for the stat/read/decode work.
  249     * @returns the raw artifact text plus the header parsed from its own first
  250     * line, or `undefined` when the session has no stored artifact.
  251     */
  252    override async readRaw(id: SessionId, signal?: AbortSignal): Promise<SessionRawArtifact | undefined> {
  253      signal?.throwIfAborted()
  254      await this.ensureRootEncoding()
  255      signal?.throwIfAborted()
  256      const path = await this.findLog(id, signal)
  257      if (path === undefined) return undefined
  258      const { buffer } = await this.readStableFile(path, signal)
  259      let content: string
  260      if (this.compression === 'zstd') {
  261        const { frames } = scanZstdFrames(buffer)
  262        if (frames.length === 0) throw new Error('empty or header-less Zstandard session log')
  263        const decoder = createZstdFrameDecoder()
  264        const plaintexts: Buffer[] = []
  265        // The decoder yields views into a reused buffer; copy each frame's
  266        // plaintext immediately so a later concat cannot read overwritten memory.
  267        for (const plaintext of decoder.decode(buffer, frames)) {
  268          signal?.throwIfAborted()
  269          plaintexts.push(Buffer.from(plaintext))
  270        }
  271        content = Buffer.concat(plaintexts).toString('utf8')
  272      } else {
  273        content = buffer.toString('utf8')
  274      }
  275      const meta = parseHeaderMeta(content.split('\n', 1)[0] as string)
  276      if (meta === undefined || meta.id !== id) {
  277        throw new Error(`corrupt session log: invalid header line in "${path}"`)
  278      }
  279      // The logical artifact name is `session.jsonl` regardless of the physical
  280      // encoding suffix (`.jsonl.zstd` marks compression only).
  281      return { meta, filename: 'session.jsonl', content }
  282    }
  283
  284    /**
  285     * Read a file's bytes under a revision-stable loop: a writer appending
  286     * between stat and readFile would yield a torn physical file, so retry
  287     * while the stat revision changes.
  288     * @param path - the artifact file to read.
  289     * @param signal - optional cancellation for the stat/read work.
  290     * @returns the stable bytes and the revision that matched both stats.
  291     */
  292    private async readStableFile(
  293      path: string,
  294      signal?: AbortSignal,
  295    ): Promise<{ buffer: Buffer; revision: PersistenceRevision }> {
  296      for (;;) {
  297        signal?.throwIfAborted()
  298        const before = fileRevision(await stat(path, { bigint: true }))
  299        const buffer = await readFile(path, { signal })
  300        signal?.throwIfAborted()
  301        const after = fileRevision(await stat(path, { bigint: true }))
  302        if (before === after) return { buffer, revision: after }
  303      }

02 · Durable and live events are separate surfaces for replay and control

SOURCE FACT

architecture.md defines session events as durable facts, agent/* as live coordination, and capability events as policy/adapter extension points.

PLAIN LANGUAGE

Replay is the black box; live control is the radio. One cannot replace the other.

IMPLICATION

Observability must state which data is recoverable and which exists only in the live process.

03 · Compaction runs at pre-step pressure and canonical overflow

SOURCE FACT

agent-lifecycle documents compaction-basic handling pressure at agent/pre-step and canonical overflow at agent/request-error; the failed step closes before a retry turn is considered.

PLAIN LANGUAGE

Compaction does not suddenly delete history; it reorganizes the request after a failed step is closed.

IMPLICATION

Compaction, retry, and event closure need an explicit order to avoid orphan tool results.

04 · JSONL records version, parent session, delegation depth, and encoding

SOURCE FACT

HeaderLine carries version, id, cwd, parentSession, origin, delegationDepth, and agentPreset; logPath selects zstd or plaintext artifacts.

PLAIN LANGUAGE

Recovery first identifies the ledger, its parent, and delegation depth before reading later events.

IMPLICATION

A session header should be a verifiable migration protocol, not a few debug fields.
