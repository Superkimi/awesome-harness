01 · Sub-agents have independent sessions, descriptors, and depth

SOURCE FACT

The subagent package centers child-agent, descriptors, delegation depth, lifecycle, and run settlement; child output is extracted from its own event suffix.

PLAIN LANGUAGE

A sub-agent is not a role inside the parent prompt; it owns another recoverable work ledger.

IMPLICATION

Delegation needs independent context, lifecycle, cancellation, and settlement—not another prompt.

   38  /**
   39   * Resolve the child's delegation depth from its parent and enforce an optional
   40   * cap. The persisted parent header is the monotone floor, so a resumed parent
   41   * cannot delegate as if it were top-level.
   42   * @param parent - the delegating parent agent.
   43   * @param maxDepth - optional absolute cap the resolved depth must not exceed.
   44   * @returns the child's non-negative safe-integer depth.
   45   * @throws {SubagentDepthError} when the resolved depth exceeds `maxDepth`.
   46   * @throws {RangeError} when the resolved depth leaves the safe-integer range.
   47   */
   48  export function resolveChildDepth(parent: Agent, maxDepth: number | undefined): number {
   49    const childDepth = delegationDepthOf(parent) + 1
   50    if (!Number.isSafeInteger(childDepth)) {
   51      throw new RangeError('subagent child depth exceeds the safe-integer range')
   52    }
   53    if (maxDepth !== undefined && childDepth > maxDepth) {
   54      throw new SubagentDepthError(childDepth, maxDepth)
   55    }
   56    return childDepth
   57  }

02 · Child-agent terminal state is derived from its own event facts

SOURCE FACT

lifecycle derives completed, error, refusal, or aborted from the child session's turn/end, dropped work, errors, and blocked events.

PLAIN LANGUAGE

A process being torn down successfully does not mean the task succeeded; the child log decides.

IMPLICATION

Collaboration results should follow task facts, not merely a thread exit code.

  220   * Why this child's epoch ended, for the terminal lifecycle edge and the
  221   * manager's own parent delivery. The child's own log is authoritative:
  222   * teardown succeeding says nothing about whether the model errored, hit its
  223   * token ceiling, or was cancelled, so deriving the reason from disposal would
  224   * report failed work as completed.
  225   *
  226   * {@link foldConsumedWork} supplies both halves the raw turn sequence cannot:
  227   * which turn accounts for the work this epoch consumed, and whether accepted
  228   * work was cancelled after it without any turn opening over it. A recorded
  229   * failure still wins over a cancellation — stopping a child that had already
  230   * failed does not turn its failure into a cancellation.
  231   * @param events - this epoch's own event suffix.
  232   * @returns its terminal stop reason; `completed` only for an epoch that both
  233   *   closed cleanly and had nothing left to run.
  234   */
  235  function epochStopReason(events: readonly SessionEvent[]): SubagentResult['stopReason'] {
  236    const { end, droppedUnrun } = foldConsumedWork(events)
  237    switch (end?.data.reason.kind) {
  238      case 'max-tokens':
  239        return 'max-tokens'
  240      case 'aborted':
  241      case 'interrupted':
  242        return 'aborted'
  243      case 'error':
  244        return 'error'
  245      // A pre-step rejection — a hook deny, a policy plugin — discarded input
  246      // this epoch had claimed: the work was declined, not done.
  247      case 'blocked':
  248        return 'refusal'
  249      // A clean ending and no accounting turn at all share one rule: the epoch
  250      // finished what it was given unless a cancelled queue says otherwise.
  251      case undefined:
  252      case 'completed':
  253        return droppedUnrun ? 'aborted' : 'completed'
  254      /* v8 ignore next 3 -- `TurnEndReason` is merge-extensible, so this arm needs a
  255       * backend that adds a variant; treating an unnameable reason as success would
  256       * report failed work as completed. */
  257      default:
  258        return 'error'
  259    }
  260  }
