01 · 多 Agent 是共享控制面的线程树，不是主循环里的递归函数

SOURCE FACT

每棵 root thread 树共享 AgentControl、registry、V2 residency、execution limiter 和 rollout budget；spawn 通过 ThreadManager 创建独立 thread，子线程继承环境与 exec policy。

PLAIN LANGUAGE

每个子 Agent 都有自己的会话账本，但兄弟们共用一张组织架构表、并发配额和总预算。

IMPLICATION

隔离了对话状态，同时能做全树限流、恢复和协作观测。

  187      fn fork_mode(&self) -> Result<Option<SpawnAgentForkMode>, FunctionCallError> {
  188          if self.fork_context.is_some() {
  189              return Err(FunctionCallError::RespondToModel(
  190                  "fork_context is not supported in MultiAgentV2; use fork_turns instead".to_string(),
  191              ));
  192          }
  193
  194          let fork_turns = self
  195              .fork_turns
  196              .as_deref()
  197              .map(str::trim)
  198              .filter(|fork_turns| !fork_turns.is_empty())
  199              .unwrap_or("all");
  200
  201          if fork_turns.eq_ignore_ascii_case("none") {
  202              return Ok(None);
  203          }
  204          if fork_turns.eq_ignore_ascii_case("all") {
  205              return Ok(Some(SpawnAgentForkMode::FullHistory));
  206          }
  207
  208          let last_n_turns = fork_turns.parse::<usize>().map_err(|_| {
  209              FunctionCallError::RespondToModel(
  210                  "fork_turns must be `none`, `all`, or a positive integer string".to_string(),
  211              )
  212          })?;
  213          if last_n_turns == 0 {
  214              return Err(FunctionCallError::RespondToModel(
  215                  "fork_turns must be `none`, `all`, or a positive integer string".to_string(),
  216              ));
  217          }
  218
  219          Ok(Some(SpawnAgentForkMode::LastNTurns(last_n_turns)))
  220      }
