01 · Git 提交是编辑事务和恢复机制

SOURCE FACT

成功编辑后默认自动提交，修改前的 dirty 文件也可先提交；/undo 只允许撤销当前会话由 Aider 创建的最近提交。

PLAIN LANGUAGE

Aider 用 Git 当保险箱：改前存一份，改后再存一份，出问题可以退回，但不会随便回滚用户自己的提交。

IMPLICATION

在代码仓库场景，VCS 原生事务比自造文件快照更透明。

SOURCE FACT
