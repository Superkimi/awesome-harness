L1factloop

01 · 交互外环 + 有界 reflection 内环

SOURCE FACT

Coder.run 持续读取用户输入；每个输入由 run_one 调用 send_message，若编辑解析、lint 或 test 产生 reflected_message，则最多再反思 3 次。

PLAIN LANGUAGE

Aider 的循环很直接：你说一次，它生成修改；修改格式错了或检查失败，就把错误原样喂回模型再试，但不会无限自修。

IMPLICATION

这是“以编辑反馈驱动的局部循环”，而非任意工具调用状态机。

SOURCE FACT

Aider 更像一条固定流水线，不是让模型临场决定下一步用什么工具。

IMPLICATION

03 · LiteLLM 是统一 Provider 适配层

SOURCE FACT

Model.send_completion 把模型名、messages、stream、temperature、可选单个 function tool 和 extra params 交给 litellm.completion；流式和非流式结果由 Coder 分别消费。

PLAIN LANGUAGE

Aider 把各家模型 API 的差异交给 LiteLLM，自己的核心只面对一套近似 OpenAI 的消息格式。

接模型很快，但 Provider 行为、重试和能力元数据也部分受 LiteLLM 语义约束。
