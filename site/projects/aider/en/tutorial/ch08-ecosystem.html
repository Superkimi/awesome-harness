01 · 核心不是 MCP/函数工具循环

SOURCE FACT

核心 Coder 的外部能力来自固定 CLI 命令、Git、文件编辑格式、lint/test、网页抓取和可选单一 function edit schema；仓库核心未实现通用 MCP 工具注册与动态插件调度。

PLAIN LANGUAGE

Aider 专注“在 Git 仓库里改代码”，不是一个可随时挂几十种业务工具的通用 Agent 平台。

IMPLICATION

专注带来可预测性和编辑深度，连接器生态与跨系统工作流则明显受限。
