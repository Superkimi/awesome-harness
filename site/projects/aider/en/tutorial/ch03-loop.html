The loop: why work keeps moving

How does one request become multiple executable steps?

Chapter 3 / 112 source findingsmain
ROUTEQuestion→Analogy→Evidence board→Four questions→Source map→Map→Line reading
Start with a concrete analogy

Like a courier reading receipts: accept work, write an action, execute, return the receipt, then decide whether to continue.

Answer the chapter question first

How does one request become multiple executable steps? Read the implementation as input, state, tool effect, receipt, and recovery—not as a feature list.

01 · 交互外环 + 有界 reflection 内环

SOURCE FACT

Coder.run 持续读取用户输入；每个输入由 run_one 调用 send_message，若编辑解析、lint 或 test 产生 reflected_message，则最多再反思 3 次。

PLAIN LANGUAGE

Aider 的循环很直接：你说一次，它生成修改；修改格式错了或检查失败，就把错误原样喂回模型再试，但不会无限自修。

IMPLICATION

这是“以编辑反馈驱动的局部循环”，而非任意工具调用状态机。

IMPLICATION
