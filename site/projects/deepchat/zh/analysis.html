01 · 结论先行

先用一句话抓住它的控制面

DeepChat 把对话运行时拆成 SessionTurn、Tape/Transcript、工具 effect、Memory lineage、ACP 与 Subagent slots。它特别适合学习“聊天产品如何升级成可恢复 Agent Harness”。

优势

  • Tape/Transcript/SQLite 为恢复和分叉提供事实源
  • Tool effect schema 区分 builtin/MCP/plugin/shell 来源
  • Subagent slot、exposure、context 与并发策略显式化

边界

  • 功能面很宽，旧 runtime 与新 harness 并存时需要 cleanup guard
  • 桌面运行时、插件、MCP、ACP 的边界较复杂
  • 高阶记忆与 Tape 机制需要配合数据模型理解
