02 · FilesystemPermission 是 first-match allow/deny/interrupt 规则

SOURCE FACT

FilesystemPermission 验证路径必须以 / 开头、禁止 .. 和 ~；_check_fs_permission 按声明顺序找第一条匹配规则，返回 allow/deny/interrupt，interrupt 交给 HumanInTheLoopMiddleware。

权限规则像防火墙：先匹配到的规则生效，读写可以拒绝，敏感路径可以暂停让人确认。

IMPLICATION

路径权限要固定顺序、拒绝目录穿越，并让“需要审批”与“直接拒绝”是不同结果。

  433  def _wildcard_delete_overlap(pattern: str, anchor: str, target: str) -> bool:
  434      """Check whether a wildcard deny pattern overlaps a recursive delete target.
  435
  436      Args:
  437          pattern: The original glob pattern (e.g. ``/work/*.log``).
  438          anchor: The longest wildcard-free prefix of ``pattern``.
  439          target: The absolute path being recursively deleted.
  440
  441      Returns:
  442          True if the pattern's matches intersect the delete subtree.
  443      """
  444      # Root anchor ("/**/x"): pattern can match anywhere, block all.
  445      if anchor == "/":
  446          return True
  447      # Target directly matches the glob: block.
  448      if wcglob.globmatch(target, pattern, flags=_FS_WCMATCH_FLAGS):
  449          return True
  450      # Anchor is inside the delete subtree: recursive delete would remove
  451      # matching descendants — block.
  452      if PurePosixPath(anchor).is_relative_to(PurePosixPath(target)):
  453          return True
  454      # Target is below the anchor: safe to allow ONLY when the pattern suffix
  455      # is a single, non-** component (fixed depth) AND no ancestor of the
  456      # target matches the glob. "/work/*.log" can never match anything under
  457      # "/work/notes.txt". But "/work/*" matches "/work/app", so deleting
  458      # "/work/app/child" mutates a denied path's contents and must be blocked.
  459      # Patterns with directory wildcards ("/work/*/secrets") could match
  460      # descendants of the target, so fail closed for those.
  461      if not PurePosixPath(target).is_relative_to(PurePosixPath(anchor)):
  462          return False
  463      anchor_parts = PurePosixPath(anchor).parts
  464      pattern_parts = PurePosixPath(pattern).parts
  465      suffix = pattern_parts[len(anchor_parts) :]
  466      if len(suffix) != 1 or "**" in suffix[0]:
  467          return True
  468      # Check whether any ancestor of the target (between anchor and target)
  469      # matches the glob. If so, the target is inside a denied directory's
  470      # subtree.
  471      target_parts = PurePosixPath(target).parts
  472      return any(
  473          wcglob.globmatch(
  474              str(PurePosixPath(*target_parts[:depth])),
  475              pattern,
  476              flags=_FS_WCMATCH_FLAGS,
  477          )
  478          for depth in range(len(anchor_parts), len(target_parts))
  479      )
