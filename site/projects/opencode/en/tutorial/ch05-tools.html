L1facttools

01 · shell 权限不是简单字符串前缀，而是 Bash/PowerShell 语法树扫描

SOURCE FACT

tree-sitter 解析 Bash/PowerShell，逐 command 生成 permission pattern 和 arity-based always pattern；对 rm/cp/mv/cat/PowerShell 文件 cmdlet 解析路径，项目外目录单独请求 external_directory。

PLAIN LANGUAGE

它会拆开一条复杂命令，分别看里面有哪些子命令和文件路径，而不是只看第一个单词。

IMPLICATION

比 startsWith 白名单稳健，但动态变量/命令替换的静态路径推断仍有天然边界。

02 · 工具注册表统一 builtin、项目脚本和 npm/file plugin 工具

SOURCE FACT

registry 初始化 read/grep/glob/edit/write/apply_patch/shell/task/web/skill/LSP 等 builtins，扫描 config directories 的 tool(s)/*.js|ts，再合并 plugin.tool；所有 plugin 输出走统一 truncation 与 tracing。

PLAIN LANGUAGE

内置扳手、项目自制工具和插件工具最后都进同一个工具箱，走同一套执行上下文。

IMPLICATION

能力面一致，但本地 JS/TS plugin 是可执行代码，信任边界等同于宿主进程。

L1facttools

03 · Edit 在写前生成 diff、请求权限，写后格式化并回送 LSP 错误

SOURCE FACT

每文件 semaphore 防并发覆盖；路径先做 external-directory check，精确/容错 replacer 计算新内容和 diff，permission metadata 携带 diff；写入保持 BOM/换行，formatter 后重新读，最后触发 file events 和 LSP diagnostics。

PLAIN LANGUAGE

先把拟修改内容展示给门卫，再落盘；落盘后自动格式化，并立刻告诉模型有没有新语法错误。

IMPLICATION

编辑是有事务边界感的工具，而非裸 fs.writeFile。
