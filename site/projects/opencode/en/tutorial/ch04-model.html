01
L1factmodelContext

01 · stream processor 把 reasoning、text、tool、usage、patch 全部事件化持久

SOURCE FACT

processor 为 reasoning/text/tool call 建 part，tool result 归一化附件；step-finish 记录 finish、cost、tokens、snapshot 和 patch，并异步更新 session summary。

PLAIN LANGUAGE

模型的思考、文字、每次工具起止和文件变化都不是终端里一闪而过，而是独立可回放的事件。

IMPLICATION

TUI、Web、Desktop、ACP 可以消费同一事件模型。

02 · Provider 层是 AI SDK 适配矩阵，不只兼容 OpenAI API

SOURCE FACT

内置动态加载 Anthropic、OpenAI/Azure、Google/Vertex、Bedrock、xAI、Mistral、Groq、Cohere、OpenRouter、GitHub Copilot 等 SDK，并为不同 provider 决定 responses/chat/messages、认证和区域模型规则。

PLAIN LANGUAGE

它不是把所有厂商硬塞成同一种 HTTP；每家方言由独立适配器翻译。

IMPLICATION

模型覆盖广，但 provider 特例数量大，回归测试成本高。

03 · 请求准备层统一合并 prompt、variant、provider options 与 hooks

SOURCE FACT

system 由 agent/provider prompt、环境/项目指令和 user system 合成；参数按 provider base→model→agent→variant 合并，plugins 可改 system、params、headers；工具按 permission 和本轮 user.tools 过滤后排序。

L1factmodelContext

04 · overflow 阈值为可用输入窗口，而非模型总窗口

SOURCE FACT

usable 优先使用 model.limit.input；否则从 context 中扣除最大输出 token，reserved 默认最多 20k。token total 达到 usable 才判 overflow，auto=false 时关闭。

PLAIN LANGUAGE

它会先给模型回答预留座位，再判断历史是否坐满，避免输入刚好塞满后没有空间输出。

IMPLICATION

比简单按 context×百分比更贴合各 provider 的 input/output 限制。

L1factmodelContext

05 · 压缩保留近期原文尾部，而不是只剩一段摘要

SOURCE FACT

默认尝试保留最近 2 个 user turn，预算为 usable 的 25%、上下限 2k–8k；若整轮放不下可从轮中切分。模型视图被重排为 compaction marker、summary、retained tail、continue。

PLAIN LANGUAGE

老故事写成摘要，最近几轮尽量保留原话；必要时甚至保留半个超长回合。

IMPLICATION

降低摘要丢失当前执行细节的风险，但消息顺序投影更复杂。

L1factmodelContext

06 · 摘要前先去媒体、限制工具输出，失败时可 replay 原请求

SOURCE FACT

compaction 对历史去除媒体并把单个工具输出限制 2000 字符；可把前次 summary 带入增量摘要，plugins 可替换 prompt/加 context。若 provider 因大媒体直接 overflow，会回退到之前 user turn，压缩后以文字占位重放。

PLAIN LANGUAGE

整理书桌前先把大图片和长日志搬走；如果一张附件让请求根本进不了门，就去掉附件后把原问题再问一次。

IMPLICATION

覆盖了“请求发送前就超限”和“响应后发现临界”两类路径。
