Do not treat one code block as the whole system. Each card separates fact, plain language, engineering impact, caveat, and a clickable pinned source.

01 · session 持久化 agent/model/permission/cost/tokens/summary/revert 与 parent

SOURCE FACT

Session row 包含 parent、agent/model、permission、input/output/reasoning/cache tokens、cost、文件统计、share、revert snapshot 和 timestamps；messages/parts 通过事件桥更新并写数据库。

PLAIN LANGUAGE

一条任务不只存聊天文本，还存它用了哪个 Agent/模型、花了多少钱、改了哪些文件、能否回退以及是谁的子任务。

IMPLICATION

为恢复、审计、成本和协作提供统一数据底座。

02 · 每个模型 step 前后用影子 Git 仓库生成可回退 patch

SOURCE FACT

processor 在 stream 前预抓 snapshot，step-finish 后 track 并 patch；Snapshot 使用独立 gitdir，复用源仓对象库/索引，忽略规则同步，跳过大于 2MiB 的未跟踪文件并只 stage 候选路径。

PLAIN LANGUAGE

每走一步都拍“修改前后”照片，照片存进旁边的 Git 仓库，不污染用户当前分支。

IMPLICATION

支持精确 diff/revert；非 Git 项目或 snapshot=false 时能力降级。

03 · Share 是显式远程同步会话、消息、parts、diff 和模型

SOURCE FACT

创建 share 后，event subscribers 将 session/message/part/session_diff/model 聚合并发到 opncd.ai 或组织 console；可用 OPENCODE_DISABLE_SHARE 全局关闭，配置还支持 share=auto。

PLAIN LANGUAGE

分享链接不是只上传一张截图，而是持续同步完整任务数据；若开了自动分享，必须按数据出境功能治理。

IMPLICATION

企业默认应关闭或接自有 console，并在 UI 明确展示共享状态与数据范围。
