Start with a concrete analogy

Context is a workbench that tidies itself: current material stays visible, old material is archived, and indexes remain recoverable.

Answer the chapter question first

What enters context, and what gets compacted or recovered? Read the implementation as input, state, tool effect, receipt, and recovery—not as a feature list.

01
L1factmodelContext

01 · Provider 边界前才做上下文变换和密钥解析

SOURCE FACT

streamAssistantResponse 在每次 provider 请求前依次执行 transformContext、convertToLlm、动态 getApiKey、动态 system prompt，然后把 Context 交给 streamFunction；流事件逐步回写 context.messages，并对 abort 生成最终 aborted message。

PLAIN LANGUAGE

上下文不会在会话开始时被一次性拍扁，长任务中每次请求都可以重新裁剪、换系统提示和刷新短期 token。

IMPLICATION

上下文压缩、OAuth refresh 和 provider 适配应放在真正发请求的边界，避免 token 过期或 stale prompt。

02 · 默认压缩预留 16384 token，尾部保留 20000 token

SOURCE FACT

DEFAULT_COMPACTION_SETTINGS 将 enabled 设为 true、reserveTokens 设为 16384、keepRecentTokens 设为 20000；shouldCompact 在 contextTokens > contextWindow - reserveTokens 时触发。

PLAIN LANGUAGE

它不会等到 provider 报 context overflow 才处理，而是提前留出一块回答空间，再保留最近工作集。

IMPLICATION

自研应把 reserve/keep 做成可见配置并在模型切换时重新计算，不要硬编码单一窗口。

L1factmodelContext

03 · Token 估算融合 provider usage 与 trailing message 估算

SOURCE FACT

estimateContextTokens 使用最后一个有效 assistant usage 作为锚点，对其后的消息用 estimateTokens 累加；没有 usage 时按角色估算，文本采用 chars/4，图片按约 4800 字符计。

PLAIN LANGUAGE

刚从模型拿到真实 token 账单就用真实数，刚塞进来的工具结果还没账单就先用保守估算，不会因为只看旧 usage 而漏算最新输入。

IMPLICATION

上下文预算应允许“真实 usage + 未结算尾巴”混合，且图片/工具输出需要有明确估算策略。

04 · Cut point 避开孤立 tool result，保留完整 tool turn

SOURCE FACT

findValidCutPoints 允许在 user/assistant/custom/bashExecution 等消息切分，明确跳过 toolResult；findCutPoint 还能检测切在 turn 中间的情况并保留 turn prefix。

PLAIN LANGUAGE

压缩不会只删掉工具调用上半段或回执下半段，避免下一轮看到一张没有出处的工具结果。

IMPLICATION

对话裁剪需要 message role invariant；“按 N 条消息截断”对 coding agent 不够安全。

05 · 摘要提示词固定为可恢复的结构化 checkpoint

SOURCE FACT

SUMMARIZATION_PROMPT 强制 Goal、Constraints & Preferences、Progress/Done/In Progress/Blocked、Key Decisions、Next Steps、Critical Context 七个区块，并要求保留精确路径、函数名和错误信息；更新摘要会合并 previous-summary。

PLAIN LANGUAGE

摘要不是一句“我们做了很多事”，而是下一任模型可以按清单接手的交接卡。

IMPLICATION

长任务的摘要模板应和恢复协议一起版本化，并对路径、错误和下一步做保真约束。

06 · 运行时支持 provider 动态系统提示和过期 token 刷新

SOURCE FACT

AgentLoopConfig 文档明确 getSystemPrompt 每次 LLM call 解析，getApiKey 可为每次调用获取短期 OAuth token；streamAssistantResponse 在请求前执行两者。

PLAIN LANGUAGE

长时间工具执行后，下一次模型调用仍能拿到最新授权和最新资源说明。

IMPLICATION

多 provider harness 应把 credential refresh 和 system prompt resolution 做成 request-time hook，而不是启动时静态读取。
