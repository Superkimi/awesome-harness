01 · MCP host 侧把 OAuth provider 与 kernel 请求分开

SOURCE FACT

McpManager refresh/config/begin_login host request 会读取 auth storage、重新获取 API key，并把解析后的 server URL/config 交给 kernel；stdio server 由 Python 自己管理，HTTP 用户 server 才在 host 侧注册 OAuth provider。

PLAIN LANGUAGE

登录凭据、UI 交互和真正的 MCP kernel 连接没有混成一条黑盒；host 只做身份和配置桥接。

IMPLICATION

连接器设计应区分 credential plane、control plane 和 tool execution plane，避免把 token 直接塞进模型上下文。
