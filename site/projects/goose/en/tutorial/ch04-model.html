01 · Provider 以流式协议统一，工具调用必须完整再上送

SOURCE FACT

Provider trait 只要求实现 stream(model, system, messages, tools)；MessageStream 可以增量返回文本，但工具调用以完整对象返回。

PLAIN LANGUAGE

不同模型厂商先被翻译成同一种“消息水管”。普通文字可以一个词一个词流出，但工具参数不能半截就执行。

IMPLICATION

Provider 适配层承担格式差异，Agent 主循环不需要为每家 API 复制控制逻辑。

02 · 80% 阈值触发结构化压缩

SOURCE FACT

当 Agent 自管上下文且估算 token/上下文上限大于阈值（默认 0.8）时触发压缩；压缩保留最新用户文本，并插入结构化摘要与继续指令。

PLAIN LANGUAGE

快塞满模型记忆时，它不会粗暴删掉全部历史，而是把旧进展整理成一张交接单，再把用户最新要求放回去。

IMPLICATION

压缩的目标不是“越短越好”，而是保留任务状态、文件改动、错误、待办和下一步。

03 · 上下文超限采用渐进式工具结果剥离和一次恢复重试

SOURCE FACT

压缩会依次尝试移除 0%、10%、20%、50%、100% 的中间工具响应；Provider 明确报上下文超限时执行恢复压缩，第二次仍超限则终止。

PLAIN LANGUAGE

先保留尽可能多的工具证据，实在放不下才逐级清掉旧工具输出；不能靠无限压缩掩盖超限。

IMPLICATION

Harness 应区分账单 token、保留 token 和可牺牲的工具噪声，并给恢复动作设次数上限。
