01 · 结论先行

先用一句话抓住它的控制面

OpenWork 把桌面工作区、OpenCode 会话和 MCP Apps 组合成一个可观察的工作台；它的关键不是“能聊天”，而是把界面状态、会话路由、插件装配和沙箱边界做成可验证的协议。

优势

  • MCP Apps / OAuth / 插件生态完整
  • 上下文快照把 UI 与执行状态显式化
  • CSP + iframe + origin 检查形成多层浏览器边界

边界

  • 主执行器依赖 OpenCode，不能把 UI 边界误认为 OS 级沙箱
  • 企业版与开源版目录交织，部署面较大
  • 工作区事件与运行时配置需要额外持久化治理
视频与字幕

把这次源码阅读做成可复习的短视频

视频只承诺页面和源码中能证明的事实；脚本、画面、SRT 与成片会在同一个视频目录中按版本留痕。
