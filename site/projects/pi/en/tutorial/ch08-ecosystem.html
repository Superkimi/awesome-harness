01 · 固定提交未实现内建 MCP client/server

SOURCE FACT

产品 runtime 枚举的 built-in tools 为 read/bash/edit/write，随后合并 SDK 和 extension tools；resource 与 extension contracts 中没有 MCP transport/session/tool discovery 实现。仓库 packages 源码检索未发现 MCP runtime contract。

PLAIN LANGUAGE

Pi 可以通过扩展接任意协议，但开箱没有像部分竞品那样配置 MCP server 后自动发现 tools/resources/prompts。

IMPLICATION

自研平台若依赖 MCP，需要额外的官方扩展或内核 connector 层。
