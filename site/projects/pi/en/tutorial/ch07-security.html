L1factsecurity

01 · Project Trust 保护仓库可执行资源，但不审批每条命令

SOURCE FACT

检测到项目 settings、extensions、skills、prompts、themes、SYSTEM/APPEND 等资源才询问 trust；headless 默认不信任。未信任时清空项目 settings 并禁止项目资源装载/写入，但 built-in bash/edit 仍没有逐命令 approval。

PLAIN LANGUAGE

它问的是“要不要加载这个仓库自带的插件和说明书”，不是“接下来这条 rm 命令能不能执行”。

IMPLICATION

resource trust 和 action authorization 是两道不同的门，报告与产品 UI 都必须分开。

L1factsecurity

02 · 本地凭据文件使用权限收紧和跨进程锁

SOURCE FACT

auth storage 创建父目录为 0700、文件为 0600，使用 proper-lockfile 串行更新并在锁内重新读取，避免多个进程覆盖外部修改；API key 也可从环境或命令动态解析。

PLAIN LANGUAGE

密钥本不仅不让其他本机用户随便看，两个 Pi 进程同时刷新 token 时也不会互相踩掉。

IMPLICATION

本地 secret hygiene 扎实，但动态命令取 key 本身仍属于受信任配置。
