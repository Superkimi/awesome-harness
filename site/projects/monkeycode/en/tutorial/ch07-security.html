01 · 隔离边界主要依赖仓库外 VM，Codex 内层 sandbox 明确关闭

SOURCE FACT

平台协议申请带 host、image、CPU、memory、git 和 TTL 的 VirtualMachine；但 Codex 模板设置 sandbox_mode=danger-full-access，并将 /workspace 标为 trusted。仓库内只有 VM API 合同，没有底层 namespace/hypervisor enforcement。

PLAIN LANGUAGE

Codex 在房间里面拿的是万能钥匙；安全取决于这个“房间”到底是不是一间真正隔离的 VM，而造房间的代码不在本仓库。

IMPLICATION

部署评审必须联审 codingmatrix/Taskflow 执行器，不能因类型名叫 VirtualMachine 就自动认定强隔离。

03 · zip 资源有文件数、单文件、总量和 zip-slip 双重校验

SOURCE FACT

默认限制 1000 文件、单文件 32MiB、总解压 256MiB；先查声明尺寸，再用 LimitReader 验证实际尺寸，并拒绝绝对路径、反斜线和 .. 逃逸。

   12  // UnzipLimits guards the in-memory unzipper against zip bombs and overly
   13  // large archives. All limits are inclusive of the value (size == limit is OK).
   14  type UnzipLimits struct {
   15  	MaxFileSize  int64 // per-entry uncompressed size
   16  	MaxTotalSize int64 // sum of all entries' uncompressed sizes
   17  	MaxFiles     int   // max number of file entries
   18  }
   19
   20  // DefaultUnzipLimits is the policy used by the Resolver.
   21  var DefaultUnzipLimits = UnzipLimits{
   22  	MaxFileSize:  32 << 20,  // 32 MiB
   23  	MaxTotalSize: 256 << 20, // 256 MiB
   24  	MaxFiles:     1000,
   25  }
   26
   27  // unzipToMemory reads a zip archive entirely from memory and returns its
   28  // regular file entries. Directories are skipped. Paths are validated to
   29  // reject zip-slip ("../..") and absolute paths. Entries that exceed the
   30  // limits cause the entire archive to be rejected so callers can fall back
   31  // to skipping the whole asset (matching the Resolver's per-skill policy).
   32  func unzipToMemory(data []byte, limits UnzipLimits) ([]MaterializedFile, error) {
   33  	zr, err := zip.NewReader(bytes.NewReader(data), int64(len(data)))
   34  	if err != nil {
   35  		return nil, fmt.Errorf("agentresource: open zip: %w", err)
   36  	}
   37
   38  	// Pre-flight file count + declared uncompressed size.
   39  	fileCount := 0
   40  	var totalDeclared uint64
   41  	for _, f := range zr.File {
   42  		if f.FileInfo().IsDir() {
   43  			continue
   44  		}
   45  		fileCount++
   46  		totalDeclared += f.UncompressedSize64
   47  	}
   48  	if fileCount > limits.MaxFiles {
   49  		return nil, fmt.Errorf("agentresource: zip has %d files, max %d", fileCount, limits.MaxFiles)
   50  	}
   51  	if totalDeclared > uint64(limits.MaxTotalSize) {
   52  		return nil, fmt.Errorf("agentresource: zip declares %d bytes total, max %d", totalDeclared, limits.MaxTotalSize)
   53  	}
   54
   55  	out := make([]MaterializedFile, 0, fileCount)
   56  	var totalRead int64
   57  	for _, f := range zr.File {
   58  		if f.FileInfo().IsDir() {
   59  			continue
   60  		}
   61
   62  		rel, err := sanitizeZipPath(f.Name)
   63  		if err != nil {
   64  			return nil, err
   65  		}
   66
   67  		// Trust-but-verify: even if UncompressedSize64 looks fine, cap
   68  		// per-entry reads to MaxFileSize via io.LimitReader.
   69  		if int64(f.UncompressedSize64) > limits.MaxFileSize {
   70  			return nil, fmt.Errorf("agentresource: zip entry %q declares %d bytes, max %d",
   71  				f.Name, f.UncompressedSize64, limits.MaxFileSize)
   72  		}
   73
   74  		rc, err := f.Open()
   75  		if err != nil {
   76  			return nil, fmt.Errorf("agentresource: open zip entry %q: %w", f.Name, err)
   77  		}
   78  		// limit + 1 so a file exactly at the limit reads cleanly but anything
   79  		// larger trips the over-cap check below.
   80  		limited := io.LimitReader(rc, limits.MaxFileSize+1)
   81  		buf, err := io.ReadAll(limited)
   82  		_ = rc.Close()
   83  		if err != nil {
   84  			return nil, fmt.Errorf("agentresource: read zip entry %q: %w", f.Name, err)
   85  		}
   86  		if int64(len(buf)) > limits.MaxFileSize {
   87  			return nil, fmt.Errorf("agentresource: zip entry %q exceeds per-file limit %d",
   88  				f.Name, limits.MaxFileSize)
   89  		}
   90  		totalRead += int64(len(buf))
   91  		if totalRead > limits.MaxTotalSize {
   92  			return nil, fmt.Errorf("agentresource: zip exceeds total limit %d after entry %q",
   93  				limits.MaxTotalSize, f.Name)
   94  		}
   95
   96  		out = append(out, MaterializedFile{RelPath: rel, Content: buf})
   97  	}
   98  	return out, nil
   99  }

SOURCE FACT

netguard 校验 http/https、特殊 IPv4 写法、localhost/private/metadata IP，并在 dial 时使用已验证 IP；测试覆盖十进制、八进制、十六进制、IPv6 和私有代理。然而示例配置明确为 SaaS 开启、私有化默认 false。

防护能力本身很认真，但自建用户照示例部署时默认不会打开这扇防火门。

IMPLICATION

需要按部署信任边界决定默认值，并在关闭时明确告警。
