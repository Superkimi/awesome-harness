02 · steering 不只在轮间排队，还能在工具执行中协作中断

01 · Task 是内建多 Agent 调度器，支持 batch、async 与结构化 yield

SOURCE FACT

TaskTool 发现 bundled/user/project agent；batch call 强制 shared context 和非空 tasks，每项可选 agent/effort/isolation/outputSchema；async 交给 job manager，sync 按 semaphore 并发并合并 usage/artifacts。子 Agent 必须通过 yield 交付，可增量分段并做 schema validation。

PLAIN LANGUAGE

IMPLICATION

比 subprocess 示例级子 Agent 更接近真正控制平面。

02 · 递归、并发、预算、闲置 park 与冷恢复都有硬合同

SOURCE FACT

默认 maxConcurrency=32、maxRecursionDepth=2、softRequestBudget=200，超过预算提示收尾、1.5x 强制 yield；idle 420 秒后可 park 到磁盘。reviver 从 session_init 恢复 cwd、tools、spawn policy、depth、MCP gate 和 yield requirement，缺失 workspace 时只保留 transcript。

IMPLICATION

长任务资源治理和 durable collaboration 明显领先多数 CLI Agent。
