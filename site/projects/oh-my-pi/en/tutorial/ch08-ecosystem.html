L1factconnectors

01 · MCP 是完整内建连接器，不是插件样例

SOURCE FACT

MCPManager 从多来源配置发现服务器，并行连接、缓存 tools、订阅 resources、接收 notifications、动态刷新；transport 支持 stdio、legacy SSE、Streamable HTTP，HTTP 保存 session id、处理 server request/notification、401/403 刷新后重试。

PLAIN LANGUAGE

它不仅能调用 MCP 工具，还管理连接、认证、资源订阅、服务端推送和重连生命周期。

IMPLICATION

连接器成熟度高，适合企业工具生态；同时需审计远端 URL、headers 和本地 command 配置。

02 · 可直接吸收 Claude、Gemini、OpenCode 等生态的 MCP 配置

SOURCE FACT

capability discovery providers 解析本产品、Claude、Gemini CLI、OpenCode、Codex、Cline、Cursor、VSCode/Windsurf 等配置；OpenCode local/remote 和 Gemini mcpServers 被归一成同一 stdio/SSE/HTTP contract，并保留 source metadata。

PLAIN LANGUAGE

用户换工具时不必手工重写全部 MCP 配置，OMP 会读取其他 Agent 的配置并统一格式。

IMPLICATION

迁移体验突出，但跨生态自动加载需有来源可见性和项目 trust。
