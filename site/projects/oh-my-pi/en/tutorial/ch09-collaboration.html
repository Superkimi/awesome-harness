01 · Task 是内建多 Agent 调度器，支持 batch、async 与结构化 yield

SOURCE FACT

TaskTool 发现 bundled/user/project agent；batch call 强制 shared context 和非空 tasks，每项可选 agent/effort/isolation/outputSchema；async 交给 job manager，sync 按 semaphore 并发并合并 usage/artifacts。子 Agent 必须通过 yield 交付，可增量分段并做 schema validation。

PLAIN LANGUAGE

主 Agent 可以一次发一组有共同背景的任务，每个工人独立选角色和输出合同；结果不是随便一段聊天，而是显式交付。

IMPLICATION

比 subprocess 示例级子 Agent 更接近真正控制平面。

LINE-BY-LINE READING
  1. 1–26
    Inputs, configuration, and state

    Identify who owns the input, which configuration is read, and which state is created.

  2. 27–53
    Branches, effects, and receipts

    Trace conditions, external calls, event writes, and failure exits instead of reading only names.

  3. after
    Return to the caller

    Follow the caller and the next event to see how this code's result is consumed.
