01 · Hook 同时支持本地命令与客户端 wire subscription

SOURCE FACT

HookEngine 按 regex 匹配并去重 server command，同时加入 wire subscriptions，并发执行；任意 result=block 即整体 block。UserPromptSubmit、Pre/PostToolUse、Stop/Failure、Compact、Notification、Subagent 等事件均接入。

PLAIN LANGUAGE

组织可以在模型动作前后插入自己的门卫/审计脚本，也可以让 IDE 客户端参与判断。

IMPLICATION

扩展面完整；engine、命令错误与超时通常 fail-open，只有成功返回 block/exit 2 才阻止。

   94          self,
   95          event: HookEventType,
   96          *,
   97          matcher_value: str = "",
   98          input_data: dict[str, Any],
   99      ) -> asyncio.Task[list[HookResult]]:
  100          """Trigger a hook in the background and keep a strong reference to the
  101          task. asyncio holds tasks in a WeakSet, so naively writing
  102          ``asyncio.create_task(engine.trigger(...))`` and discarding the local
  103          variable lets Python's GC collect the still-pending task — which fires
  104          ``loop.call_exception_handler`` with no exception field and surfaces as
  105          ``Unhandled exception in event loop / Exception None`` in the
  106          prompt_toolkit terminal. Use this helper any time the caller wants to
  107          fire a hook without awaiting its completion.
  108          """
  109          task: asyncio.Task[list[HookResult]] = asyncio.create_task(
  110              self.trigger(event, matcher_value=matcher_value, input_data=input_data)
  111          )
  112          self._pending_fire_and_forget.add(task)
  113          task.add_done_callback(self._pending_fire_and_forget.discard)
  114          task.add_done_callback(self._log_fire_and_forget_failure)

02 · 插件工具是经审批的本地子进程，可获得新鲜 Host 凭证

SOURCE FACT

PluginTool 每次调用先请求 action=plugin:name 审批，把 JSON params 写 stdin，在插件目录执行声明 command，120 秒超时；inject mapping 可把当前 API key/base URL 注入干净环境。插件安装校验名称防 path traversal，并用同文件系统 staging swap。

PLAIN LANGUAGE

插件本质是本机程序，不是受限脚本；它能按配置拿到主机凭证，所以安装来源和权限同样重要。

IMPLICATION

能力强但供应链风险高；approval 只确认“运行插件”，不审计插件内部每个文件/网络动作。

   81          if self._approval is not None:
   82              description = f"Run plugin tool `{self.name}`."

   84                  return ToolRejectedError()

   86          params_json = json.dumps(kwargs, ensure_ascii=False)

  101              stdout, stderr = await asyncio.wait_for(

  134      plugins_dir: Path, config: Config, *, approval: Approval | None = None
  135  ) -> list[PluginTool]:

  139      if not plugins_dir.is_dir():

03 · MCP 延迟启动、逐服务器状态化，并对富媒体共享 100K 字符预算

SOURCE FACT

agent 可 defer MCP，首个 agent loop 后台启动并等待，向 UI 发 loading/status；server 状态区分 connected/unauthorized/failed。MCP 结果的文本、image/audio/video data URL 共用 100000 字符预算，超额媒体丢弃并加 truncation notice。

PLAIN LANGUAGE

远程工具不必拖慢 CLI 启动，但真正开始工作前会等它们连好；一个巨型网页 DOM 或截图不能把上下文塞爆。

IMPLICATION

体验和上下文安全较好；首轮仍会被 MCP 连接完成阻塞，OAuth token 持久落在 share dir。
