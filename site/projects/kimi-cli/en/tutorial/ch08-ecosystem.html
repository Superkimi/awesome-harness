01 · Hook 同时支持本地命令与客户端 wire subscription

SOURCE FACT

HookEngine 按 regex 匹配并去重 server command，同时加入 wire subscriptions，并发执行；任意 result=block 即整体 block。UserPromptSubmit、Pre/PostToolUse、Stop/Failure、Compact、Notification、Subagent 等事件均接入。

PLAIN LANGUAGE

组织可以在模型动作前后插入自己的门卫/审计脚本，也可以让 IDE 客户端参与判断。

IMPLICATION

扩展面完整；engine、命令错误与超时通常 fail-open，只有成功返回 block/exit 2 才阻止。

   94          self,

   96          *,

   99      ) -> asyncio.Task[list[HookResult]]:
  100          """Trigger a hook in the background and keep a strong reference to the
  101          task. asyncio holds tasks in a WeakSet, so naively writing
  102          ``asyncio.create_task(engine.trigger(...))`` and discarding the local
  103          variable lets Python's GC collect the still-pending task — which fires
  104          ``loop.call_exception_handler`` with no exception field and surfaces as

  107          fire a hook without awaiting its completion.

02 · 插件工具是经审批的本地子进程，可获得新鲜 Host 凭证

SOURCE FACT

PluginTool 每次调用先请求 action=plugin:name 审批，把 JSON params 写 stdin，在插件目录执行声明 command，120 秒超时；inject mapping 可把当前 API key/base URL 注入干净环境。插件安装校验名称防 path traversal，并用同文件系统 staging swap。

PLAIN LANGUAGE

插件本质是本机程序，不是受限脚本；它能按配置拿到主机凭证，所以安装来源和权限同样重要。

IMPLICATION

能力强但供应链风险高；approval 只确认“运行插件”，不审计插件内部每个文件/网络动作。

   87  async def load_agents_md(work_dir: KaosPath) -> str | None:
   88      """Discover and merge ``AGENTS.md`` files from the project root down to *work_dir*.
   89
   90      For each directory on the path, the following candidates are checked in order:
   91
   92      1. ``.kimi/AGENTS.md``  — project-local kimi config (highest priority)
   93      2. ``AGENTS.md``        — standard location
   94      3. ``agents.md``        — lowercase variant (mutually exclusive with 2)
   95
   96      Within a single directory, ``.kimi/AGENTS.md`` and ``AGENTS.md``/``agents.md``
   97      are **both** loaded (with ``.kimi/`` first), but ``AGENTS.md`` and ``agents.md``
   98      are mutually exclusive (uppercase wins).
   99
  100      All discovered files are concatenated root→leaf, separated by ``\\n\\n``, with
  101      source annotations.  Total size is capped at :data:`_AGENTS_MD_MAX_BYTES`.
  102      Budget is allocated leaf-first so deeper (more specific) files are never
  103      truncated in favour of shallower ones.
  104      """
  105      project_root = await find_project_root(work_dir)
  106      dirs = await _dirs_root_to_leaf(work_dir, project_root)
  107
  108      # Phase 1: collect all candidate files (root → leaf order)
  109      discovered: list[tuple[KaosPath, str]] = []  # (path, content)
  110      for d in dirs:
  111          # .kimi/AGENTS.md is always checked independently (can coexist with root-level file)
  112          kimi_path = d / ".kimi" / "AGENTS.md"
  113          # AGENTS.md and agents.md are mutually exclusive (uppercase wins)
  114          root_candidates = [d / "AGENTS.md", d / "agents.md"]
  115
  116          candidates: list[KaosPath] = []
  117          if await kimi_path.is_file():
  118              candidates.append(kimi_path)
  119          for rc in root_candidates:
  120              if await rc.is_file():
  121                  candidates.append(rc)
  122                  break
  123
  124          for path in candidates:
  125              content = (await path.read_text()).strip()
  126              if content:
  127                  discovered.append((path, content))
  128                  logger.info("Loaded agents.md: {path}", path=path)
  129
  130      if not discovered:
  131          logger.info(
  132              "No AGENTS.md found from {root} to {cwd}",
  133              root=project_root,
  134              cwd=work_dir,
  135          )
  136          return None
  137
  138      # Phase 2: allocate budget leaf-first so deeper (more specific) files
  139      # are never truncated in favour of shallower ones.
  140      # The annotation overhead (<!-- From: ... -->\n and \n\n separators)
  141      # is included in the budget so the final output never exceeds the limit.
  142      remaining = _AGENTS_MD_MAX_BYTES
  143      budgeted: list[tuple[KaosPath, str]] = [None] * len(discovered)  # type: ignore[list-item]
  144      for i in reversed(range(len(discovered))):
  145          path, content = discovered[i]
  146          annotation = f"<!-- From: {path} -->\n"
  147          # Reserve space for the annotation and the \n\n separator between parts
  148          separator_cost = len(b"\n\n") if i < len(discovered) - 1 else 0
  149          overhead = len(annotation.encode()) + separator_cost
  150          remaining -= overhead
  151          if remaining <= 0:
  152              budgeted[i] = (path, "")
  153              remaining = 0
  154              continue
  155          encoded = content.encode()
  156          if len(encoded) > remaining:
  157              content = encoded[:remaining].decode(errors="ignore").strip()
  158              logger.warning("AGENTS.md truncated due to size limit: {path}", path=path)
  159          remaining -= len(content.encode())
  160          budgeted[i] = (path, content)
  161
  162      # Phase 3: assemble in root → leaf order, skipping entries emptied by truncation
  163      parts: list[str] = []
  164      for path, content in budgeted:
  165          if content:
