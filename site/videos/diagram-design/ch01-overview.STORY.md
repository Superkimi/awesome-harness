# Diagram Design · M01 · 总览：先知道它解决什么问题

## Hook
上次汇报的图没人看懂，这次我先问清楚“这张图要表达什么”。

## Proof
- skills/diagram-design/SKILL.md · semantic pattern|behavior|state
- skills/diagram-design/SKILL.md · agent|generate|semantic
- skills/diagram-design/SKILL.md · complexity budget|split

## Lesson
先证明一个真实工作结果，再追问它为什么能稳定完成：把它想成一本会被 Agent 读取的制图规范：先问图要表达什么，再决定用架构图、时序图、状态机还是数据流。

## Limitation
它治理的是图的生成规范，不是执行 Agent
