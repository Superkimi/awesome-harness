## Hook
模型还没说完工具就开始准备，我沿 query 看它怎样补齐不完整的 tool result。

## Evidence anchors
- claude-code-loop-001: src/query.ts:460-666 · 主 Harness 是一个持续循环的消息变换与工具执行流水线
  - 每一轮不是“问一次模型就结束”，而是先整理行李、调用模型、执行动作、把结果记账，再决定继续还是停。
- claude-code-loop-002: src/query.ts:971-1124 · 工具可以随流式响应提前启动，并补齐协议不完整的 tool result
  - 模型还在吐后续内容时，已经完整的工具参数可以先开工；账本缺一张回执时，系统会补一张失败回执，避免下一轮 API 拒绝整段对话。

## Takeaway
上下文、工具、权限和恢复都在同一编排循环交汇，修改其中任何一步都可能影响缓存与 transcript 一致性。
