READING CONTRACT

为什么要做成教程，而不是再写一份报告

报告适合查一个事实：某个函数在哪、某个权限是不是 fail-closed、某个压缩阈值是多少。教程要解决另一件事：让第一次接触 Coding Agent 的人，能把这些事实串成一条因果链。每个课程页都采用“生活比喻 → 概念对比 → 技术链路 → 源码摘录 → 迁移练习 → 下一站”的节奏。

每一条结论都带四个标签固定 commit源码路径 + 行号事实 / 推断 / 风险对应架构与时序图
